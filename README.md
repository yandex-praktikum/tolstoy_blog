# Учебный блог с дневниками Льва Толстого

Готовый сайт для уроков авторизации. Нужен Python 3.14.

```text
python -m venv venv
```

Windows: `venv\Scripts\Activate.ps1`. Linux/macOS: `python3.14 -m venv venv`, затем `source venv/bin/activate`.

```text
python -m pip install -r requirements.txt
python manage.py runserver 127.0.0.1:8000
```

Откройте http://127.0.0.1:8000/. Пользователь `test_parser_user`, пароль `testpassword`. База пользователя и страницы уже
подготовлены; оставьте сервер запущенным, пока выполняете уроки. В другом терминале запускайте парсер. Остановка сервера
— Ctrl+C.

Сам сайт после установки зависимостей работает без интернета. Блог содержит 37 записей на 8 страницах, страницы авторов и
пагинацию. CSS, форма входа, CSRF и сессии обслуживаются локально.

Если база удалена: `python manage.py migrate`, затем `python manage.py loaddata diary`. Проверка проекта:
`python manage.py test`.

Для самостоятельной практики Scrapy нужен открытый блог:

```text
python manage.py runserver 127.0.0.1:8001 --settings=training_blog.public_settings
```

Его адрес — http://127.0.0.1:8001/. Блог содержит 71 запись, 4 группы и страницы пагинации. Вход не нужен. В темах
авторизации используйте режим на порту 8000; в практике Scrapy — режим на порту 8001. Их можно запускать по очереди или в
разных терминалах.
